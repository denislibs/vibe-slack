# KT-client (6.2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A client-side verifier (TypeScript) that proves an identity→device-keys binding against the KT Merkle log — RFC 6962 hashing, canonical-leaf parsing, inclusion + consistency proofs, and STH signature verification — matching the Go server byte-for-byte.

**Architecture:** `client/src/shared/lib/kt/` (FSD infrastructure). SHA-256 via `@noble/hashes`, Ed25519 via `@noble/ed25519` (deterministic across browser/jsdom/node). A typed KT HTTP client; a `KTClient.verifyIdentity` orchestrator holding the last trusted STH and checking monotonicity via consistency proofs. Correctness is proven by an interop fixture captured from the real Go KT service.

**Tech Stack:** TypeScript, vitest, `@noble/hashes`, `@noble/ed25519`.

**Byte contracts (verified in `backend/internal/kt/{leaf.go,sth.go}` + `httpapi/kt_handlers.go`):**
- Canonical leaf (big-endian): `id_len(u32) ‖ identity ‖ version(u64) ‖ count(u32) ‖ for each key sorted-asc-by-bytes: key_len(u32) ‖ key`.
- Leaf hash: `SHA-256(0x00 ‖ canonical)`. Node hash: `SHA-256(0x01 ‖ left ‖ right)`.
- STH signed message: `"KTSTHv1" ‖ tree_size(u64 BE) ‖ root_hash`, Ed25519.
- Wire (all bytes base64-std): `/kt/pubkey`→`{kt_public_key}`; `/kt/sth`→`{tree_size, root_hash, signature}`; `/kt/key/{identity}`→`{leaf_index, version, device_set, audit_path[], sth}` where **`device_set` is the base64 of the canonical leaf bytes**; `/kt/proof/inclusion?leaf_index&tree_size`→`{leaf_index, tree_size, audit_path[]}`; `/kt/proof/consistency?from&to`→`{from, to, proof[]}`.
- Existing FE conventions: typed HTTP client like `client/src/shared/api/as.ts`/`workspace.ts`; vitest in jsdom; some crypto tests use `// @vitest-environment node`.

```ts
import { sha256 } from "@noble/hashes/sha256";

function u32(n: number): Uint8Array {
  const b = new Uint8Array(4); new DataView(b.buffer).setUint32(0, n, false); return b;
}
function u64(n: bigint): Uint8Array {
  const b = new Uint8Array(8); new DataView(b.buffer).setBigUint64(0, n, false); return b;
}
function concat(parts: Uint8Array[]): Uint8Array {
  const len = parts.reduce((a, p) => a + p.length, 0);
  const out = new Uint8Array(len); let o = 0;
  for (const p of parts) { out.set(p, o); o += p.length; }
  return out;
}
function cmp(a: Uint8Array, b: Uint8Array): number {
  const n = Math.min(a.length, b.length);
  for (let i = 0; i < n; i++) if (a[i] !== b[i]) return a[i] - b[i];
  return a.length - b.length;
}

// canonicalLeaf mirrors backend kt.CanonicalLeaf exactly (keys sorted asc by raw bytes).
export function canonicalLeaf(identity: string, version: bigint, deviceSet: Uint8Array[]): Uint8Array {
  const keys = [...deviceSet].sort(cmp);
  const id = new TextEncoder().encode(identity);
  const parts: Uint8Array[] = [u32(id.length), id, u64(version), u32(keys.length)];
  for (const k of keys) { parts.push(u32(k.length), k); }
  return concat(parts);
}

export function parseCanonicalLeaf(buf: Uint8Array): { identity: string; version: bigint; keys: Uint8Array[] } {
  const dv = new DataView(buf.buffer, buf.byteOffset, buf.byteLength);
  let o = 0;
  const idLen = dv.getUint32(o, false); o += 4;
  const identity = new TextDecoder().decode(buf.subarray(o, o + idLen)); o += idLen;
  const version = dv.getBigUint64(o, false); o += 8;
  const count = dv.getUint32(o, false); o += 4;
  const keys: Uint8Array[] = [];
  for (let i = 0; i < count; i++) {
    const kl = dv.getUint32(o, false); o += 4;
    keys.push(buf.subarray(o, o + kl)); o += kl;
  }
  return { identity, version, keys };
}

export function leafHash(canonical: Uint8Array): Uint8Array {
  return sha256(concat([new Uint8Array([0x00]), canonical]));
}
export function nodeHash(left: Uint8Array, right: Uint8Array): Uint8Array {
  return sha256(concat([new Uint8Array([0x01]), left, right]));
}
```

### Task 5: KTClient.verifyIdentity + interop fixture

**Files:** Create `client/src/shared/lib/kt/client.ts`, `client.test.ts`; `client/src/shared/lib/kt/testdata/kt_vectors.json`; Create `backend/internal/kt/export_vectors_test.go` (emits the fixture).

`KTClient` deps: the KT api client + the trusted KT pubkey (fetched once, pinned) + an in-memory `trustedSTH` (`{treeSize, rootHash}`).
```ts
verifyIdentity(token, identity): Promise<Uint8Array[]>  // returns the verified device signing keys
```
Flow (per spec):
1. `pub ← pubKey()` (cache).
2. `rec ← key(identity)`; if 404 → throw `KTNotPublished`.
3. `await verifySTHSignature(pub, rec.sth)` else throw `KTInvalidSTH`.
4. monotonicity: if `trustedSTH` set and `trustedSTH.treeSize <= rec.sth.treeSize` → `proof = consistency(trustedSTH.treeSize, rec.sth.treeSize)`, `verifyConsistency(trustedSTH.rootHash, trustedSTH.treeSize, rec.sth.rootHash, rec.sth.treeSize, proof)` else throw `KTForked`. Update `trustedSTH = rec.sth`.
5. `verifyInclusion(leafHash(rec.deviceSet), rec.leafIndex, rec.sth.treeSize, rec.auditPath, rec.sth.rootHash)` else throw `KTInvalidInclusion`.
6. `parsed = parseCanonicalLeaf(rec.deviceSet)`; assert `parsed.identity === identity` (else throw); return `parsed.keys`.
